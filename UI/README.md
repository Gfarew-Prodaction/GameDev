# Интерфейс Звезда 57

Полностью перерисованы все 35 элементов из `Zvezda_57_UI_katalog_35_elementov.docx`. Новые файлы `UI-001.svg`–`UI-035.svg` заменяют прежние макеты по тем же адресам. 29 элементов P0, 4 P1 и 2 P2. Открыть каталог: [UI](./index.html).

Это комплект макетов и графических компонентов. Он не содержит работающей сцены Unity, игровых контроллеров или готового Windows-билда. Кабинет на фоне — иллюстрация из предоставленного документа, а не скриншот из билда.

Размеры на карточках и в окне просмотра добавлены из `Zvezda_57_UI_katalog_35_elementov_s_razmerami.docx`. Для всех 35 элементов отдельно указаны рекомендуемые габариты на экране 1920×1080, расположение и размеры экспорта графики. Эти рекомендации не являются измерениями PNG-превью. Полные значения доступны в поле `dimensions` файлов `catalog.json` и `manifest.json`.

## Файлы

- `UI-001.svg`–`UI-035.svg` — основные редактируемые исходники 1920×1080. Текст остаётся текстом. SVG можно открыть в браузере, Inkscape, Illustrator или импортировать в Figma.
- `Previews/1080p` — полноразмерные PNG; `Previews/720p` — версии 1280×720 для проверки читаемости.
- `Previews/overview.png` — все 35 макетов на одном листе.
- `Source/Artboards` — три варианта экрана UI-030; `Source/Components` — прозрачные подложки, пиктограммы, оттиски, кнопки, маркеры и фоны концовок в SVG.
- `Sprites` — PNG-компоненты с прозрачностью. У подложек кнопок и документов нет запечённых динамических надписей.
- `Materials/design-tokens.json` — палитра, размеры, шрифты, длительности эффектов и пять состояний кнопок.
- `catalog.json` — требования к каждому элементу, извлечённые из документа; `manifest.json` — требования и пути к готовым файлам.
- `Reference/office.jpg` — предоставленная иллюстрация кабинета.

## В Unity

1. Импортировать необходимые PNG из `Sprites`, выбрать `Texture Type: Sprite (2D and UI)`, включить прозрачность. Не импортировать целиком PNG-макет как игровой интерфейс.
2. Для бумажных и металлических подложек установить границы спрайта 16 px, затем использовать `Image Type: Sliced`. Подложки без текста рассчитаны на изменение размеров.
3. Добавить `Canvas Scaler` с опорным разрешением 1920×1080, режимом `Scale With Screen Size` и `Match` около 0.5. Безопасные поля — не менее 48 px в опорном разрешении.
4. Все ФИО, суммы, телефоны, статусы, таймеры и реплики выводить отдельными текстовыми компонентами. Для кириллицы подготовить шрифтовой атлас TextMeshPro. Семейства в макетах: Arial, Georgia и Courier New; файлы проприетарных шрифтов в репозиторий не включены. Перед распространением выбрать лицензированные шрифты с кириллицей.
5. Собрать переиспользуемые префабы кнопки, карточки происшествия и карточки улучшения. Числа, цена и эффекты берутся из игровых данных; значения на макетах демонстрационные.
6. Привязать пять состояний кнопки, маркеры и лампы к состоянию игры. Продублировать цвет текстом или символом. Не подсвечивать ошибку в документе до подтверждения игроком.
7. При паузе останавливать игровые таймеры. Предметы, штампы, карта и штекеры остаются объектами сцены; макеты показывают оформление и расположение UI поверх них.

## Визуальные варианты

UI-002: два фона и три состояния кнопки возврата. UI-013: три оттиска. UI-020: тревога, принято, завершено. UI-022: четыре состояния экипажа. UI-027: шесть эмблем и четыре состояния карточки. UI-030: пуск, пустой город и аварийная тьма. UI-034: пять состояний для бумажной и металлической кнопки.

Фоны концовок — самостоятельные векторные концепты, а не финальный живописный арт. Макет титров задаёт структуру; фактический состав команды, авторов музыки и лицензий должен быть заполнен владельцами проекта перед сдачей. Эти сведения не выдумывались.

## Воспроизведение

Запустить из корня репозитория:

```sh
python3 tools/design-ui.py
node tools/export-ui.mjs
python3 tools/update-catalog.py
python3 -m http.server 4173
```

Для экспорта нужен Node.js и пакет `sharp`. `NTO_NODE_MODULES` позволяет указать путь к уже установленным пакетам. Генератор не перерисовывает листы 3D-моделей.

## Источники графики

Требования и иллюстрация кабинета предоставлены пользователем в DOCX. Векторный интерфейс, пиктограммы и три фона концовок созданы программно в ходе этого обновления. Дополнительные сторонние фотографии или аудиозаписи не использовались. Генеративные модели для новых изображений не применялись.
