# Звезда-57 · Особый сектор

Статическая галерея из 50 эскизов моделей в PNG и 35 полностью обновлённых макетов интерфейса в SVG. Все UI перерисованы по каталогу 35 элементов от 13 ноября 2026; старые макеты заменены. В галерее есть поиск по названию или ID, фильтры по зоне и приоритету, полноразмерный просмотр, связанные листы и скачивание.

Откройте `index.html` локально. Для GitHub Pages выберите публикацию из корня ветки с этим файлом в настройках **Settings → Pages → Deploy from a branch**. Сборка и зависимости не нужны.

Для UI есть [отдельный каталог](UI/index.html), PNG 1920×1080 и 1280×720, три варианта концовки, прозрачные компоненты и [инструкция передачи в Unity](UI/README.md). Надписи в SVG редактируются; динамические строки не запечены в подложки компонентов.

Первоначальные рисунки моделей и кабинета подготовлены с ImageGen. Промпты их правок приведены внизу основной галереи. Новый UI — векторные исходники; фоновая иллюстрация взята из предоставленного документа.
