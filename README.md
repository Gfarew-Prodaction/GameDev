# Звезда-57 · Особый сектор

Статическая галерея из 50 эскизов моделей в PNG и 35 макетов интерфейса в SVG. В галерее есть поиск по названию или ID, фильтры по зоне и приоритету, полноразмерный просмотр, связанные листы и скачивание.

Откройте `index.html` локально. Для GitHub Pages выберите публикацию из корня ветки с этим файлом в настройках **Settings → Pages → Deploy from a branch**. Сборка и зависимости не нужны.

Изображения подготовлены с ImageGen. Промпты последних правок приведены внизу галереи.
